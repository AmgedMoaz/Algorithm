# Algorithm

A collection of **algorithm implementations and problem-solving exercises** designed to build a strong understanding of algorithms, data structures, and computational thinking.

## 📌 About

This repository focuses on learning and implementing different algorithms, including:

* Searching algorithms
* Sorting algorithms
* Recursion and backtracking
* Divide and conquer
* Greedy algorithms
* Dynamic programming
* Graph algorithms
* Tree algorithms
* String algorithms
* Basic and advanced data structures
* Time and space complexity analysis
* Algorithmic problem-solving and optimization

The main goal of this repository is to understand **how algorithms work, how to implement them, and how to choose the most efficient approach for a given problem**.

## 🛠️ Tech Stack

* **Languages:** C++ & Java
